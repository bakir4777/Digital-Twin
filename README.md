# Визуализация отдувки метанола

Приложение на Streamlit и Plotly: интерактивные графики температуры, давления,
расхода водометанольного раствора и массового содержания метанола.
Есть выбор периода, последние значения, статистика и экспорт выбранных данных.
Синтетические данные воспроизводимы и служат только для демонстрации интерфейса.

## Запуск

### Windows, Python 3.15

Распакуйте ZIP и дважды нажмите `start_windows.bat` в папке с `app.py`.
Скрипт создаст окружение на установленном Python 3.15, установит зависимости
и запустит приложение. При первом запуске нужен интернет. Не закрывайте
окно во время работы. Адрес в браузере: http://localhost:8501.
Обновление менеджера Python не требуется.

### Linux / облачная среда

Python 3.12 или новее:

```bash
cd /workspace/Digital-Twin
python -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m streamlit run app.py --server.headless true
```

## Excel

В боковой панели скачайте пример, заполните измерения и выберите режим Excel.
Поддерживаются `.xlsx`, выбор листа и сопоставление собственных названий столбцов.
Единицы автоматически не пересчитываются.

| Столбец шаблона | Значение |
| --- | --- |
| timestamp | Дата и время Excel или текст `2026-01-01 12:00:00` |
| temperature | Температура, °C |
| pressure | Давление, бар |
| flow | Расход ВМР, м³/ч |
| methanol | Содержание метанола, % масс. (например, 15 означает 15%) |

Одна строка — одно измерение всех четырёх параметров. Даты должны быть уникальными,
значения заполненными и конечными. Поддерживаются десятичные запятые.
Давление и расход неотрицательны, содержание метанола — от 0 до 100.
Измерения автоматически сортируются по времени.
Данные обрабатываются текущим сервером приложения без сохранения загруженного файла на диск.

## Проверки

`requirements.lock` фиксирует проверенные версии всех зависимостей;
`requirements.txt` задаёт диапазоны для последующего обновления.

```bash
.venv/bin/python -m unittest discover -s tests -v
```
